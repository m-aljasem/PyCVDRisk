# PyCVDRisk website

Next.js site for the PyCVDRisk package. Model data is generated from the package itself, so every
example on the site is a real call with its real output:

```bash
# from the repository root
PYTHONPATH=src venv/bin/python website/scripts/make_models.py   # writes data/models.json, public/sitemap.xml, public/robots.txt
cd website && npm install && npm run build
```

Images are in `public/images/regions/`; their sources and licences are in `data/photos.json` and
shown on `/credits`. The maps, the Framingham sign and the social preview image are generated by
`scripts/make_maps.py`, `scripts/make_sign.py` and `scripts/make_og.py`.
